# CineScope

Кіносайт із каталогом фільмів, пошуком, фільтрами, трейлерами, обраним і рецензіями.

Frontend звертається лише до власного backend. Backend проксіює TMDB API, кешує відповіді та зображення, зберігає користувачів, обране й рецензії та повертає фронтенду один готовий обʼєкт фільму.

## Стек

- Frontend: React 19, Vite, React Router
- Backend: Node.js, Express
- Авторизація: JWT, bcrypt
- Дані користувачів: JSON-сховище `backend/data/store.json`
- TMDB: API-проксі, TTL-кеш у памʼяті, дискове кешування зображень
- Без ключа TMDB сайт працює на вбудованому демо-каталозі

## Запуск

Потрібен Node.js 20+.

```bash
npm run install:all
```

Створіть `backend/.env` на основі `backend/.env.example`:

```env
PORT=3001
JWT_SECRET=your-long-random-secret
TMDB_API_KEY=your-v3-api-key
TMDB_ACCESS_TOKEN=your-v4-read-access-token
CACHE_TTL_SECONDS=600
CORS_ORIGIN=http://localhost:5173
```

Достатньо заповнити або `TMDB_API_KEY`, або `TMDB_ACCESS_TOKEN`. Без них backend автоматично використовує демо-каталог.

Запуск у режимі розробки:

```bash
npm run dev
```

- Сайт: `http://localhost:5173`
- API: `http://localhost:3001/api`

Збірка та запуск однією командою:

```bash
npm run build
npm start
```

Після збірки Express віддає frontend і API на `http://localhost:3001`.

## Основні можливості

- Головна сторінка з hero-блоком, каталогом, пагінацією, хедером і футером
- Пошук за назвою
- Фільтри за жанром, роком і рейтингом
- Сортування за популярністю, рейтингом, роком і назвою
- Сторінка фільму: постер, опис, жанри, рік, рейтинг, тривалість, трейлер, актори
- Кнопка «Дивитися фільм»: веде на офіційний сервіс перегляду (дані JustWatch через TMDB); якщо сервісів немає — позначка «Незабаром» і сторінка `/movie/:id/watch`
- Блок «Де дивитися легально» зі списком сервісів (підписка, безкоштовно, оренда, купівля)
- Каталог обмежено 15 сторінками (`MAX_PAGES` у `backend/src/catalogue.js`)
- Обране для авторизованих користувачів
- Рецензії, середня оцінка глядачів і форма відгуку
- Реєстрація, вхід і JWT-сесія
- Адаптивний інтерфейс

## API

| Метод | Маршрут | Опис |
| --- | --- | --- |
| GET | `/api/health` | Стан API та режим даних |
| POST | `/api/auth/register` | Реєстрація |
| POST | `/api/auth/login` | Вхід |
| GET | `/api/auth/me` | Поточний користувач |
| GET | `/api/movies` | Каталог із фільтрами та пагінацією |
| GET | `/api/movies/search` | Пошук фільмів |
| GET | `/api/movies/genres` | Список жанрів |
| GET | `/api/movies/:id` | Деталі фільму, трейлер, рецензії та обране |
| GET | `/api/movies/:id/reviews` | Рецензії фільму |

## Власний відеоплеєр

Фільми, які можна дивитися прямо на сайті, описуються у `backend/videos.json` (ключ — TMDB id фільму, `sources` — прямі посилання на .mp4/.webm/.mov). Для таких фільмів на сторінці `/movie/:id/watch` з'являється плеєр (перемотка, гучність, швидкість, якість, повний екран, гарячі клавіші). Додавайте лише відео, на які є права: власні, public domain або з дозволом правовласника.

## Дані про перегляд

Список легальних сервісів береться з TMDB (`watch/providers`, джерело — JustWatch) для регіонів UA, PL, US. Сам сайт фільми не відтворює: кнопка веде на сторінку фільму на сервісі.

## Примітка TMDB

Дані про фільми надає TMDB. Цей продукт використовує TMDB API, але не схвалений і не сертифікований TMDB.

## Що подивитися?

Кнопка «Що подивитися?» у шапці відкриває вікно з випадковим фільмом: рейтинг від 7.0 і від 500 оцінок (TMDB). Можна обрати жанр і натиснути «Інший фільм» — показані фільми не повторюються. Запит: `GET /api/movies/random?genre=<id>&exclude=<id,id>`. Без ключа TMDB вибір іде з демо-каталогу.

## Екскурсія по сайту

Під час першого візиту з'являється привітання «Показати, як тут усе працює?». Екскурсія підсвічує пошук, фільтри, картку фільму, кнопку «Що подивитися?» та «Обране». Повторно її можна запустити кнопкою «?» у шапці. Факт проходження зберігається в браузері (`localStorage`, ключ `cinescope_tour_done`). Компонент: `frontend/src/components/GuideTour.jsx`.

## Вікторина

Сторінка `/quiz` («Вікторина» в шапці): 10 питань «Вгадай фільм за кадром» та «Вгадай фільм за описом» (назва в описі приховується). Питання формуються з каталогу TMDB, а без ключа — з демо-каталогу. Після останнього питання показується слайд «А чи знали ви?» з цікавим фактом про кіно (`frontend/src/quizFacts.js`), потім результат. Запит: `GET /api/movies/quiz?count=10`. Підтримуються гарячі клавіші 1–4 (вибір) і Enter (далі).
